Sampai Dengan PHP versi 4. 

PHP Global Array Variable | Keterangan |
---|---|
$HTTP_POST_FILES['varfile']['name'] | Nama file asal pada mesin client. |
$HTTP_POST_FILES['varfile']['size'] | Ukuran file yang diupload dalam byte. |
$HTTP_POST_FILES['varfile']['tmp_name'] | Nama file temporer dari file yang diupload yang disimpan dalam server |

Mulai dari PHP Versi 4.1 dan PHP Versi berikutnya. 

PHP Global Array Variable | Keterangan |
---|---|
$_FILES['varfile']['name'] | Nama file asal pada mesin client. |
$_FILES['varfile']['size'] | Ukuran file yang diupload dalam byte. |
$_FILES['varfile']['tmp_name'] | Nama file temporer dari file yang diupload yang disimpan dalam server |
$_FILES['varfile']['type'] | Tipe mime dari file yang diupload |
