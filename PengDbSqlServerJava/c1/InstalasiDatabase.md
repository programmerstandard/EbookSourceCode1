## Membuat Database

Membuat database melalui Microsoft SQL Server Enterprise Manager merupakan cara termudah, sehingga mudah untuk dipahami.

1. Jalankan Enterprise Manager.
2. Tekan tanda + pada "Microsoft SQL Server", kemudian tekan tanda + pada "SQL Server Group", lalu buka server yang ada. Berikutnya Anda dapat memilih folder Databases.
3. Selanjutnya tekan menu bar "Action", kemudian pilih "New Database".
4. Berikutnya akan tampil window "Database Properties". Ketikkan nama database "Java" yang akan Anda buat pada kotak teks "Name".
5. Selanjutnya, tekan tab "Data Files", yang mana pada bagian ini berisi tentang letak dari file PRIMARY Database. Untuk menentukan perkembangan file database Anda dapat memilih dalam persen atau Megabyte, serta tentukan maksimal file database dalam megabyte atau tak terbatas.
6. Selanjutnya, tekan tab "Transnation Log", Anda akan menentukan letak dari file Log Database,besarnya perkembangan ukuran file tersebut, serta batas maksimal dari file Log Database. Tekan tombol OK untuk memproses pembuatan database.
